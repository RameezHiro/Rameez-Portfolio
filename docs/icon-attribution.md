## Marks deliberately not used

- **Visual Studio Code**: Microsoft-related marks were removed from Simple
  Icons for legal reasons ([simple-icons#11482](https://github.com/simple-icons/simple-icons/issues/11482)).
  The row uses Lucide's `code` concept instead.
- **Groq**: Simple Icons closed the request because Groq's terms permit logo
  use only with explicit permission ([simple-icons#14063](https://github.com/simple-icons/simple-icons/issues/14063)).
  The row uses Lucide's `zap` concept (fast inference) instead.
- **Google Antigravity**: not yet available in Simple Icons; the open request
  is [simple-icons#14867](https://github.com/simple-icons/simple-icons/issues/14867).
  The row uses Lucide's `orbit` concept instead.
- **Generic disciplines** (machine learning, statistics, data analysis, REST
  APIs, backend architecture) have no brand mark and use Lucide concepts.
